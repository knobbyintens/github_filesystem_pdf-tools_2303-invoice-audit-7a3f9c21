# Procurement Invoice Audit Repository

This repository holds the current invoice packet for the quarterly procurement audit.

- `invoices/` - one PDF per submitted invoice document
- `policies/invoice_audit_policy.md` - the audit policy and decision codes
- `vendor_registry.csv` - the approved vendor list and vendor status
- `audit/audit_report.json` - the published audit report (created by the auditor)

Invoice documents must be reviewed in full; the document reference and the invoice
number are different values.
